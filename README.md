# 🚢 Titanic Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to understand the characteristics of passengers, identify survival patterns, and extract meaningful insights through data cleaning and visualization.

---

## 🎯 Objectives

- Explore the Titanic dataset
- Clean and preprocess the data
- Handle missing values
- Analyze passenger demographics
- Study survival patterns
- Visualize relationships between different features

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset Features

The dataset contains information such as:

- Passenger ID
- Survived
- Passenger Class (Pclass)
- Name
- Sex
- Age
- Siblings/Spouses Aboard (SibSp)
- Parents/Children Aboard (Parch)
- Fare
- Embarked Port

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/payalsinghal633-ui/Titanic-EDA.git
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

Open the notebook:

```bash
jupyter notebook Titanic_EDA.ipynb
```

Run all cells.
